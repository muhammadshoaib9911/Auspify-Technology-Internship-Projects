# 🎬 Netflix Content Recommendation System

## 📌 Auspify Technologies – Machine Learning Internship

This project was developed as **Task 1** of my **Machine Learning Internship at Auspify Technologies**.

The goal of this project is to build a **content-based recommendation system** that recommends Netflix movies and TV shows similar to a selected title based on content-related features.

---

## 🚀 Project Overview

Recommendation systems are widely used by platforms such as Netflix, YouTube, Amazon, and Spotify to provide personalized content suggestions.

In this project, I developed a **Content-Based Recommendation System** using:

- Feature Engineering
- TF-IDF Vectorization
- Cosine Similarity
- Scikit-learn
- Python
- Pandas

The system analyzes information such as:

- Type
- Director
- Country
- Rating
- Genres/Categories

and calculates similarity between Netflix titles.

---

## 🎯 Project Objective

The main objective is to:

1. Prepare content-related features.
2. Convert text data into machine-readable numerical vectors.
3. Calculate similarity between Netflix titles.
4. Generate recommendations for a selected title.
5. Display similarity scores.
6. Build an interactive recommendation interface.

---

## 🧠 Recommendation Approach

This project uses a **Content-Based Filtering** approach.
